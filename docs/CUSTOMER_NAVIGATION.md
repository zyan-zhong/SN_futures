# 客户任务导向导航

本轮将专业终端导航从“技术模块堆叠”调整为“客户任务流程”。

## 主导航

1. **总览**：查看系统是否可用、数据质量、当前研究观察和主要风险。
2. **刷新与数据源**：一键刷新、查看行情/新闻/报告/预测状态和数据源问题。
3. **行情与新闻**：查看行情历史图、新闻事件和事件证据。
4. **预测观察**：查看七周期方向、概率、风险提示和“暂无交易点位”状态。
5. **回测验证**：查看 walk-forward、成本敏感性和历史验证摘要。
6. **报告中心**：查看日报、周报、月报和事件报告。
7. **设置与诊断**：配置本机密钥、查看运行期诊断和日志位置。

## 高级模式 / 技术明细

以下能力保留，但不再放在首层主导航突出展示：

- 因子诊断
- 模型治理
- 持仓情景
- provider 详细状态
- raw JSON / 开发调试信息

## 设计边界

- 不删除原有功能，只调整入口层级。
- 普通客户优先看到“能不能用、缺什么、下一步做什么”。
- 技术细节默认折叠，避免一打开终端就被工程字段淹没。
