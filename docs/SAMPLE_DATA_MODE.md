# 样例数据模式

SNInsightTerminal 的样例数据模式用于解决首次安装后“没有 API key、没有刷新缓存、页面全空”的体验问题。它只演示终端结构、图表样式、新闻列表和报告中心，不代表真实行情、真实预测或真实回测。

## 为什么需要样例模式

首次安装后，用户数据目录通常还没有以下运行期文件：

- `outputs/sn_market_history.json`
- `outputs/sn_unified_forecast.json`
- `outputs/events/news_events.json`
- `reports/sn_daily_report.md`

如果这些文件都不存在，专业终端会显示 `sample_mode=true` 的样例数据，帮助用户理解界面结构和下一步操作。

## 样例不是预测

样例数据有硬性约束：

- 所有样例 payload 都带有 `sample=true` 和 `sample_mode=true`。
- 页面顶部显示“样例数据模式”。
- 图表带有 `Sample / 样例` 水印。
- 预测卡片信号固定为“观望”。
- `entry`、`stop_loss`、`take_profit` 全部为空。
- 样例新闻标题以 `[样例]` 开头。
- 样例报告明确写明“样例报告，不构成投资建议。”
- 样例数据不写入真实预测文件，不进入模型训练、回测或 promotion gate。

## 如何关闭样例模式

进入“系统设置”，关闭“是否显示样例数据”。关闭后，如果尚无真实数据，页面会显示空状态和刷新引导。

## 如何刷新真实数据

点击 Dashboard 或数据源状态页的“一键刷新数据”。刷新任务会尝试生成：

- 行情历史
- 新闻事件
- 事件证据
- 预测缓存
- 报告文件

真实刷新状态文件生成后，样例模式会自动退场。若外部数据源失败，终端会显示失败原因或数据不足说明，不会用样例冒充真实预测。

## 如何判断当前是不是样例模式

可以通过以下方式判断：

- 页面顶部是否显示“样例数据模式”。
- 图表是否有 `Sample / 样例` 水印。
- API payload 是否包含 `sample_mode=true`。
- 新闻标题是否以 `[样例]` 开头。
- 报告是否显示“样例报告，不构成投资建议。”

合规声明：本系统仅供沪锡期货量化投研参考，不构成投资建议，不承诺收益，不接实盘交易。
