# UX Copy Rules

Terminal copy should be short, factual, and action-oriented.

## Length Limits

- Page intro: no more than two lines.
- Card subtitle: no more than one line.
- Card title: target 12 Chinese characters or fewer.
- Technical explanations: folded into professional details.

## Empty State Pattern

Use three parts:

1. 当前状态
2. 原因
3. 下一步

Avoid long paragraphs in empty states.

## Forbidden Presentation

Do not show:

- `undefined`
- `null`
- `NaN`
- fake prediction
- 建议买入
- 建议卖出
- 保证盈利
- raw API key names or full keys in user-facing diagnostics

## Task Text

Task labels should be short:

- 空闲
- 刷新中
- 排队
- 完成
- 失败

Task details belong in the drawer or professional mode, not in the main page flow.

## Compliance Text

Keep a single footer compliance statement. Avoid repeating long disclaimers inside every card unless a page specifically shows research backtest or prediction boundaries.
