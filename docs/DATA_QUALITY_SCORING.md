# 数据质量评分说明

数据质量不再使用固定的 0.60/0.62 兜底分，而是由多个分项加权计算，范围为 0 到 1。

## 分项权重

- 最新行情：30%
- 历史行情：20%
- 新闻数据：15%
- 事件证据：10%
- 报告输出：10%
- 预测卡片：10%
- 模型健康：5%

## 标签

- `优秀`：评分 >= 0.85
- `可用`：评分 >= 0.70
- `需谨慎`：评分 >= 0.45
- `数据不足`：评分 < 0.45
- `样例数据`：样例模式，不计入真实质量

## 降级原因

系统会同时输出：

- `blocking_reasons`：阻断真实预测或真实展示的原因，例如缺少最新行情、缺少历史行情、缺少真实预测。
- `degradation_reasons`：降级原因，例如行情来自缓存、新闻源未配置、事件证据为空。
- `next_actions_zh`：用户下一步建议，例如刷新行情、刷新新闻、生成报告。

## 非交易时段

非交易时段不会简单把行情判定为失败。实时行情 TTL 过期但处于休市时，会显示“非交易时段等待更新”，避免周末、节假日、午休或夜盘休市导致误报。

## 样例模式

样例数据只用于展示界面结构，不参与模型训练、模型治理或真实质量评分。样例模式的质量标签为“样例数据”，评分为 0。
