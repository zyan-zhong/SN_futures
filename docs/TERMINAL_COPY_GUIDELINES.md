# Terminal Copy Guidelines

## 页面说明

- 页面顶部说明不超过 2 行。
- 卡片说明不超过 1 行。
- 长技术解释放入折叠区或高级诊断。
- 重复免责声明不在每张卡片重复，统一放页面底部或报告底部。

## 空状态

空状态使用三段式：

- 状态：当前有什么。
- 原因：为什么没有数据。
- 下一步：用户可以做什么。

示例：

```text
状态：暂无研究回测收益曲线。
原因：candidate 未训练或 v4 readiness blocked。
下一步：先构建 Feature Store/训练数据，再运行研究回测。
```

## 禁止文案

- 建议买入
- 建议卖出
- 保证盈利
- 保证上涨/下跌
- fake prediction

## 专业表达

- “行情分析”不能写成“预测”。
- “研究回测”不能写成“实盘表现”。
- “缓存展示”不能写成“实时行情正常”。
- “高置信 OOF”不能写成“未来收益保证”。
