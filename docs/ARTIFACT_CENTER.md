# Artifact Center

Artifact Center is the unified research archive surface in the report center. It lists files and run directories produced by the real-data research workflow without publishing an active model or generating customer predictions.

## Included Artifacts

- `outputs/research_runs`
- Feature Store manifests
- Training dataset manifests
- Candidate registries
- OOF traces
- High-confidence reports
- Institutional validation reports
- Equity curves
- Drawdown curves
- Trades
- Research backtest reports
- Release and customer reports

## Supported Actions

- View artifact status and run count.
- List JSON, CSV, Markdown, and Parquet artifact paths.
- Copy a sanitized diagnostic summary.
- Refresh the artifact listing.

The UI shows local file paths for audit and handoff. It does not expose API keys and does not serve private bundle seed files.

## Research Boundary

Artifact Center is for review and archival. It does not train models, does not promote active models, does not generate customer predictions, and does not alter promotion gates.
