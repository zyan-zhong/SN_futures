# 沪锡期货量化投研终端 PRD

## 标准化合规风险提示

本终端仅服务于上海期货交易所沪锡期货（`SN`）的研究、监控、回测、仿真与合规风控场景。所有展示的预测结果、研究信号、风险评分、价格区间、仓位建议仅为量化投研参考，不构成实际交易建议、收益承诺或保本承诺。

## 1. 产品定位

- 产品名称：`SN Insight Terminal`
- 目标用户：期货公司有色研究、资管、CTA、产业客户套保团队、专业投资者
- 核心价值：
  - 沪锡专属数据中台
  - 多周期价格预测与风险预警
  - 机构级回测与策略仿真
  - 自动化投研报告与合规校验

## 2. 用户角色

| 角色 | 权限 |
| --- | --- |
| 研究员 | 查看行情、模型、报告；提交注释 |
| 基金经理 | 查看预测、信号、回测、风险看板 |
| 风控 | 查看风险、压力测试、熔断、账户风险 |
| 合规 | 审核推送内容、查看审计日志、维护禁用语 |
| 管理员 | 管理用户、数据源、模型版本、权限 |

## 3. 页面信息架构

1. 首页仪表盘
2. 行情与产业链数据中心
3. 多周期预测与信号中心
4. 风险预警中心
5. 回测与仿真中心
6. 因子与模型监控中心
7. 投研报告中心
8. 个人中心与合规管理

## 4. 核心模块需求

### 4.1 行情与产业链数据中心

#### 功能

- 实时展示主力合约、活跃月、跨期价差、主连连续图
- 支持 `Tick/1m/5m/15m/30m/1h/1d` 切换
- 叠加：
  - SHFE 仓单
  - LME 库存
  - SMM 升贴水
  - 进口盈亏
  - 保税区库存
- 新闻流自动分类：供给冲击、需求冲击、宏观冲击、流动性冲击

#### 可视化

- K 线 + 研究信号 + ATR 止损线
- 现货升贴水与基差趋势图
- 库存变化瀑布图
- 多空持仓结构图

### 4.2 多周期预测与信号中心

#### 功能

- 四周期预测卡片：
  - 超短
  - 波段
  - 趋势
  - 中长期
- 每个周期展示：
  - 预测价格区间
  - 上涨/下跌概率
  - 综合置信度
  - 市场状态
  - SHAP 归因
- 研究信号必须显示：
  - 信号类型：多头优势监测 / 空头优势监测 / 观望
  - 参考区间
  - 风险预算
  - 研究止盈 / 研究止损
  - 风险等级

#### 交互

- 点击单条预测可下钻至因子贡献、模型一致性、训练窗口、历史同类信号表现

### 4.3 风险预警中心

#### 功能

- 红/黄/蓝三级预警实时推送
- 支持阈值自定义与静默时间配置
- 支持预警追踪：
  - 触发原因
  - 触发时刻
  - 后续 1/3/5 日行情验证
- 模型失效预警、因子衰减预警、账户风险预警并行展示

#### 交互

- 红色预警需强制弹窗 + 审计记录
- 黄色预警顶部横幅
- 蓝色预警侧边提醒

### 4.4 回测与仿真中心

#### 功能

- 回测参数管理：
  - 训练窗
  - 验证窗
  - 测试窗
  - 手续费/滑点快照
- 历史交易明细、收益曲线、回撤曲线、分状态统计
- 模拟盘运行与实盘规则映射
- 模型版本对比、策略版本对比

#### 图表

- 净值曲线 + 回撤双轴图
- 胜率/盈亏比分组柱图
- 事件驱动收益归因图

### 4.5 因子与模型监控中心

#### 功能

- 因子树：
  - 技术
  - 量仓
  - 基本面
  - 宏观
  - 事件
  - 风险
- 展示 IC、ICIR、半衰期、VIF、近 6 个月稳定性
- 模型库：
  - 当前在线版本
  - 备选版本
  - 退役版本
- 失效预警：
  - 连续亏损
  - 胜率偏离
  - 逻辑背离

### 4.6 投研报告中心

#### 功能

- 日度/周度/月度报告一键生成
- 重大事件专题报告模板
- PDF/Word/Markdown 导出
- 自动附加风险提示和免责声明

### 4.7 个人中心与合规管理

#### 功能

- 账号、角色、数据权限、模型权限
- 短信/邮件/系统消息推送设置
- 禁用语词典维护
- 合规水印、免责声明模板、日志审计

## 5. 交互细节

### 5.1 首页仪表盘

- 左上：最新综合预测
- 左中：最高等级预警
- 右上：当前市场状态与置信度
- 中部：主力合约 K 线 + 研究信号
- 底部：
  - 库存与升贴水
  - 模型滚动胜率
  - 回测净值
  - 最新事件流

### 5.2 状态颜色体系

- 红色：高风险 / 红色预警
- 橙色：高波动监测
- 黄色：中风险
- 蓝色：提示级事件
- 绿色：风险受控

## 6. 前后端与服务架构

### 6.1 前端

- React + TypeScript
- ECharts + TradingView
- TanStack Query 管理数据拉取
- 状态管理：Zustand/Redux Toolkit

### 6.2 后端

- FastAPI 提供 REST + WebSocket
- 任务编排：Airflow/Prefect
- 模型服务：Python Worker + Redis Queue
- 报告服务：Jinja2 + Pandoc/WeasyPrint

### 6.3 数据层

- InfluxDB/TDengine：行情、因子、预测、回测时间序列
- PostgreSQL：用户、权限、元数据、审计
- Redis：缓存、推送队列、预警总线

### 6.4 安全与审计

- 单点登录
- 角色权限控制
- 敏感操作审计
- 数据传输加密
- 研究信号推送留痕

## 7. 合规规则引擎

### 7.1 禁止输出

- 保本、稳赚、保证收益、稳赢、必涨、必跌
- 明确代客交易指令
- 对收益、胜率的承诺式表述

### 7.2 必须输出

- 风险揭示
- 适当性提示
- “仅供研究参考，不构成投资建议”
- 模型版本、数据时间戳、规则快照

## 8. 非功能性要求

- 行情延迟：研究版 < 1 秒
- 预测刷新：日频模型收盘后 5 分钟内完成
- 风险预警：高优先级事件 < 3 秒
- 可用性：99.5%+
- 审计日志保留：不少于 5 年
