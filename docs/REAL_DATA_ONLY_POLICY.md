# 真实数据优先策略

## 0.3.3-beta.1 real-market-only 发行约束

- 真实行情来自 provider 链路或明确标记的 last good cache。
- last good cache 不能作为新行情，只能作为缓存展示。
- sample data 只能用于 UI 演示，不能进入真实分析、预测、回测或模型治理。
- 外部 provider 失败时必须显示失败原因和下一步建议，不能用随机数或静态 baseline 填空。
- 无 active model 时不生成预测；真实历史行情不足时不生成回测。

## 禁止项

本项目不允许用以下内容冒充真实行情、预测或回测：

- 随机行情。
- 样例行情。
- 静态演示行情。
- baseline 预测。
- baseline 回测。
- 旧缓存伪装成新行情。

## 行情使用规则

- 实时行情成功但历史行情不足时，只展示最新价。
- 历史行情成功但实时价失败时，可以绘制历史图和做后续真实分析准备。
- 只有缓存时，只显示缓存，并标记 `from_cache=true`。
- 缓存过期仍可展示，但必须标记 stale，不能生成新的真实预测。

## 预测与回测门禁

只有满足以下条件，刷新任务才允许继续真实预测/回测链路：

- 真实历史行情不少于 60 条。
- 当前不是 sample mode。
- 当前不是 cache-only。
- 存在可用 active 模型或现有真实预测服务返回有效结果。

不满足时写明原因，例如：

- “真实历史行情不足 60 条，未生成预测/回测。”
- “暂无可用 active 模型或有效预测结果，未生成预测。”
- “当前仅有缓存行情，未生成新的真实预测。”

## 样例数据边界

样例数据只用于首次安装界面演示，必须醒目标记“样例数据”。样例数据不得进入模型训练、真实预测、真实回测和 promotion gate。
