# Public Terminal Function Matrix

This matrix is the customer-facing functional coverage map for Public Terminal and the dev/legacy workspaces. Public flows must use mock/fake data in E2E, must not train, predict, backtest, build Feature Store, call real providers, or run legacy refresh/all.
