# 沪锡期货机构级高精度预测预警模型全方案

## 标准化合规风险提示

期货及衍生品交易具有高风险、杠杆与流动性冲击特征。本文档所有模型、因子、信号、区间预测、风险评分、回测结果、报告模板与软件设计，均仅用于上海期货交易所沪锡期货（`SN`）的量化投研参考、仿真验证与风险管理研究，不构成任何形式的收益承诺、保本承诺、代客理财承诺或确定性买卖建议。所有实盘应用必须在投资者适当性匹配、合规审查、仿真验证、权限审批与持续风控监控通过后方可上线。

## 1. 沪锡品种特性与价格驱动底层逻辑

### 1.1 沪锡的交易与产业属性

- 沪锡是上期所有色品种中最典型的“供给脆弱 + 库存低位 + 事件弹性高”品种。
- 供给端高度集中于缅甸、印尼、刚果（金）等区域，矿山扰动、出口政策、冶炼检修都会直接改变国内冶炼原料平衡。
- 需求端核心集中于焊料、半导体、光伏、电子制造，具有明显的景气传导与库存周期属性。
- 内外盘联动强，LME 锡、美元、人民币汇率、进口窗口盈亏与保税区库存对沪锡定价影响显著。
- 现货升贴水、仓单与注销仓单、前 20 席位持仓结构、挤仓风险是沪锡相对其他有色品种更重要的微观结构变量。

### 1.2 不同预测周期的核心驱动

| 预测周期 | 主导驱动 | 核心特征 | 推荐模型 |
| --- | --- | --- | --- |
| 5/15/30 分钟 | 盘口流动性、资金流、隔夜伦锡、日内趋势延续 | 噪声高、状态切换快 | LSTM/GRU、TFT、微观结构树模型 |
| 1-5 交易日 | 现货升贴水、仓单、库存边际变化、主力持仓、事件冲击 | 最适合多因子 + 状态识别 | RF/XGBoost/LightGBM + Stacking |
| 1-4 周 | 供需缺口、产业链开工率、进口盈亏、宏观预期 | 趋势与基本面共振明显 | VAR/协整 + 多因子机器学习 |
| 1-3 个月 | 全球供需平衡、产业景气、政策与汇率周期 | 基本面定价更强 | 供需平衡表 + 计量模型 |

### 1.3 沪锡专属交易规则与风控边界

- 上期所现行锡期货业务细则于 `2026-01-01` 发布，锡期货交易单位为 `1 吨/手`，最小变动价位为 `10 元/吨`，合约月份为 `1-12 月`。
- 锡期货标准合约文本显示最低交易保证金为合约价值的 `5%`，但这只是合约标准下限，不等于实时交易保证金。
- 需要按最新通知动态同步风控参数。以上期所 `2026-02-05` 通知为例，自 `2026-02-09` 起，锡期货已上市合约涨跌停板幅度调整为 `12%`，一般持仓交易保证金比例调整为 `14%`，套保持仓为 `13%`。
- 收费标准不能写死在代码中。上期所公开收费表检索到的最近更新时间为 `2025-05-07`，锡期货交易手续费显示为 `3 元/手`，但生产环境必须每日读取“收费标准 + 结算参数表 + 临时公告”三层规则。

### 1.4 研发目标的正确表述方式

- 把“样本外方向胜率 ≥70%、盈亏比 ≥2.5:1、年化夏普 ≥2.2、最大回撤 ≤15%”定义为研发门槛与滚动考核标准，而不是收益承诺。
- 任何时候都只能表述为“目标值”“准入线”“验收阈值”“样本外验证要求”，不得表述为“保证达到”。

### 2.2 数据模型与主键

- 主时间轴：以中国交易日 `T` 的沪锡收盘时间为主锚点。
- 高频样本：只允许使用 `T` 日收盘前已形成的聚合特征，禁止 `T+1` 修正。
- 表主键建议：
  - `market_sn_bar(symbol, ts, freq)`
  - `market_sn_orderbook(symbol, ts, level)`
  - `shfe_member_position(trade_date, member, contract)`
  - `sn_fundamental(trade_date, metric_name)`
  - `sn_event(event_time, event_type, source, impact_score)`

### 2.3 数据预处理刚性规则

1. 缺失值：仅允许 `forward fill + 事件交叉验证`。
2. 异常值：仅修正采集错误，不平滑真实极端行情。
3. 时间对齐：全部映射到 `T` 日可获得信息集。
4. 平稳性：对价格水平、库存、汇率等做 `ADF`；对价差体系做 `Johansen` 协整检验。
5. 标准化：使用滚动窗口 `Z-score`，窗口长度与训练窗口一致。
6. 数据泄露防控：
   - 不允许随机切分。
   - 不允许全样本标准化。
   - 不允许使用未来公告修正历史口径。

### 2.4 另类高频数据扩展

- 港口到港 ETA、船舶轨迹、保税区提单状态
- 冶炼厂检修公告结构化抽取
- 下游焊料企业订单指数
- 半导体封测排产与光伏焊带开工代理变量
- 锡矿运输时效与边境通关天数

### 3.7 风险因子

- 市场整体波动率
- 大宗商品贝塔
- 流动性风险
- 汇率风险
- 政策风险
- 交割月临近挤仓风险

### 3.8 因子有效性检验流程

1. 月度滚动 IC：保留 `|IC| >= 0.06`、`ICIR >= 0.6`、`p < 0.05` 的因子。
2. VIF：剔除 `VIF >= 5` 的高度共线因子。
3. 单调性：十等分组合收益至少 7 档单调。
4. 半衰期：对信号衰减做指数拟合，短于持有期的因子降权。
5. 分状态稳定性：上涨/下跌/宽震/窄震均需通过阈值。
6. 月度滚动重筛：严禁全样本一次性选因子。

## 4. 市场状态识别模型

### 4.1 状态定义

- `UPTREND`：上涨趋势
- `DOWNTREND`：下跌趋势
- `WIDE_RANGE`：宽幅震荡
- `NARROW_RANGE`：窄幅震荡

### 4.2 输入特征

- 趋势：`ret_5`、`ema_spread_5_20`、`adx_14`
- 波动：`hv_20`、`atr_14`、`range_vol_pct`
- 活跃度：`volume_chg_5`、`oi_chg_5`
- 资金结构：`net_long_top20_chg`、`concentration_gap`
- 产业格局：`supply_gap`、`inventory_to_consumption`、`spot_premium_mom`

### 4.3 建模方案

1. 用 `KMeans/GMM` 做粗分类，形成初始状态中心。
2. 用 `Gaussian HMM` 估计状态转移概率矩阵。
3. 依据簇内收益均值与波动率分位数重命名四类状态。
4. 生产环境必须滚动拟合，只能用 `T` 日以前数据识别 `T` 日状态。

### 4.4 状态适配规则

- `UPTREND`：趋势因子权重上调，止盈放宽。
- `DOWNTREND`：空头研究信号阈值上调，库存与美元权重上调。
- `WIDE_RANGE`：事件模型、波动率模型、止损保护优先。
- `NARROW_RANGE`：均值回归与基差类因子权重上调。

## 5. 多模型集成预测架构

### 5.1 四层架构

1. 基准层：ARIMA、VAR、协整、EGARCH/GJR-GARCH、EWMA 波动。
2. 阿尔法层：XGBoost、LightGBM、RF、LSTM/GRU、TFT、CNN-LSTM。
3. 融合层：Walk Forward Stacking。
4. 可解释层：SHAP/LIME + 经济逻辑一致性校验。

### 5.2 预测目标

- 回归目标：`future_return_h`
- 分类目标：`direction_h = 1(future_return_h > 0)`
- 区间目标：`[pred - z * sigma, pred + z * sigma]`
- 极端目标：`P(|return| > EVT_threshold)`

### 5.3 Walk Forward Stacking

1. 周度重训，训练窗 `6 个月`，验证窗 `1 个月`。
2. 第一层基模型分别输出：
   - 预测收益
   - 上涨概率
   - 波动率预测
   - 置信度分项
3. 第二层元模型输入第一层输出与状态标签，使用带正则化的线性模型或 LightGBM。
4. 全过程只允许时间序列切分。

### 5.4 置信度评分

综合置信度：

`Confidence = 0.30 * ModelAgreement + 0.20 * FundamentalScore + 0.20 * TechnicalScore + 0.15 * EventScore + 0.15 * RegimeFit`

分数范围 `0-100`。只有综合置信度 `>= 85` 才允许触发研究信号推送。

### 5.5 可解释性红线

- 单次预测必须输出前三大驱动因子与贡献方向。
- 全局重要性每周更新，若与经济逻辑持续背离，则降低模型权重或退役。
- 报告文案必须自动附加“研究参考，不构成投资建议”。

### 5.6 过拟合防控

- 训练/验证/样本外测试按时间划分 `70%/15%/15%`。
- 最近 2 年完整样本为主测试区间。
- 样本内外胜率差 > `8%` 直接判定过拟合。
- 所有模型启用正则化、早停、dropout 或树深度约束。

## 6. 机构级回测体系

### 6.1 回测框架

- 回测引擎：Backtrader/VNPY/RQ/JQData 任一，生产推荐 `vn.py CTA + 自定义成本层`
- 验证方式：`Walk Forward Analysis`
- 基础粒度：日频 + 30 分钟补充，高频单独环境

### 6.2 成本与执行假设

- 手续费：从交易所收费表和结算参数表动态同步
- 滑点：
  - 常态：`1 tick`
  - 开盘/收盘/极端波动：`2 ticks`
- 保证金与涨跌停：按当日有效公告参数
- 仓位硬约束：
  - 单笔风险 <= 账户权益 `1%`
  - 单边保证金占用 <= `20%`
  - 总保证金占用 <= `40%`

### 6.3 评价指标

- 收益：累计收益、年化收益、超额收益
- 风险调整后收益：夏普、卡玛、索提诺
- 风险：最大回撤、年化波动、下行波动、尾部风险
- 交易：胜率、盈亏比、平均盈亏、持仓周期、连续盈亏次数
- 归因：趋势收益、基本面收益、事件收益、成本侵蚀

### 6.4 验收门槛

- 夏普 `>= 2.2`
- 卡玛 `>= 1.5`
- 最大回撤 `<= 15%`
- 样本外方向胜率 `>= 70%`
- 盈亏比 `>= 2.5`

### 6.5 回测报告模板字段

- 区间：训练窗、测试窗、极端行情子区间
- 交易成本：手续费、滑点、保证金参数快照
- 策略表现：收益、回撤、胜率、盈亏比
- 风险事件：红黄蓝预警命中统计
- 失效诊断：因子衰减、状态误判、事件错杀

## 7. 全流程风控体系

### 7.1 事前风控

- 低于 `85` 分的预测统一标记“低置信度，不建议作为高权重参考”
- 研究信号需同步展示：
  - 参考区间
  - 风险预算
  - ATR 止损线
  - 压力测试亏损

### 7.2 事中风控

#### 红色预警

- 沪锡日内波动 > `3%`
- 主产国出口禁令、矿山停产、冶炼事故
- 美联储超预期政策冲击
- 模型失效预警
- 账户单日亏损 > `3%`

#### 黄色预警

- 库存大幅偏离预期
- 冶炼厂集中检修
- 进出口数据超预期
- 波动率 > 历史 `95%` 分位
- 主力持仓异动
- 连续两个交易日亏损

#### 蓝色预警

- 常规新闻
- 技术指标超买超卖
- 宏观数据例行发布
- 因子有效性下降
- 置信度下降

### 7.3 事后风控

- 每日：盈亏归因 + 信号复盘
- 每周：风控阈值回顾 + 参数校准
- 强制熔断：单周亏损 > `5%`，暂停研究信号输出

## 8. 模型自迭代优化方案

- 每日：预测偏差、胜率、信号复盘
- 每周：模型绩效监控、状态识别稳定性检查
- 每月：因子 IC/ICIR/VIF 重估，剔除衰减因子
- 每季度：贝叶斯优化超参数，只允许低频更新
- 每半年：极端行情专项训练与压力测试

### 8.1 失效预警触发器

- 连续 `5` 笔研究信号失败
- 滚动窗口胜率 < `60%`
- 最大回撤越过阈值
- 预测结论与经济逻辑持续背离

### 8.2 强制退役

- 连续 `3` 个滚动窗口达不到验收门槛，自动退役模型
